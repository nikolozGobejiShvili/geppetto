# Geppetto: საიტი და ადმინპანელი

ხის სათამაშოების კატალოგი ქართულად და ინგლისურად, ადმინპანელით.

## ინტერნეტში

საიტი გამოქვეყნებულია Railway-ზე, პროექტში `geppetto`:

- საიტი: https://geppetto.up.railway.app
- ადმინპანელი: https://geppetto.up.railway.app/admin

ონლაინ საიტის მონაცემები Railway-ის მუდმივ დისკზე ინახება (`/data`) და ხელახალი გამოქვეყნებისას არ იკარგება. ამ კომპიუტერზე გაშვებულ საიტს ცალკე მონაცემები აქვს (`data`), ამიტომ ერთზე შეტანილი ცვლილება მეორეზე არ ჩანს. სათამაშოები და ტექსტები ონლაინ ადმინპანელში შეცვალე.

კოდის ცვლილებების გამოსაქვეყნებლად (`.railwayignore` ადგილობრივ `data` საქაღალდეს არ ატვირთავს):

```
railway up --project 4617f225-a79f-4061-87f7-9f2a8c75c4f2 --environment production --service geppetto
```

ონლაინ ადმინპანელის პაროლი თუ დაგავიწყდა, ეს ბრძანება ახალ პაროლს დაბეჭდავს:

```
railway ssh --project 4617f225-a79f-4061-87f7-9f2a8c75c4f2 --environment production --service geppetto -- npm run reset-password
```

## გაშვება ამ კომპიუტერზე

საჭიროა Node.js 24 ან უფრო ახალი. პირველად გაუშვი `npm install`, შემდეგ ყოველ ჯერზე:

```
npm start
```

- საიტი: http://localhost:3000
- ადმინპანელი: http://localhost:3000/admin

გასაჩერებლად ტერმინალში დააჭირე `Ctrl+C`.

## პაროლი

საწყისი პაროლი ჩანს მხოლოდ პირველი გაშვებისას. შესვლის შემდეგ შეცვალე გვერდზე „პაროლი“.

თუ დაგავიწყდა, გააჩერე საიტი და გაუშვი:

```
npm run reset-password
```

ბრძანება ახალ პაროლს დაბეჭდავს.

## მონაცემების სარეზერვო ასლი

ყველა სათამაშო, ტექსტი და ატვირთული ფოტო ინახება საქაღალდეში `data`. სარეზერვო ასლისთვის გააჩერე საიტი და დააკოპირე ეს საქაღალდე სხვა ადგილას. აღსადგენად ჩასვი ის უკან, იმავე ადგილას.

## შეკვეთის ღილაკი

სათამაშოს გვერდზე ღილაკი „შეკვეთა“ აჩვენებს WhatsApp-ის, Instagram-ისა და Facebook-ის ლოგოებს. გამოჩნდება მხოლოდ ის, რაც გვერდზე „კონტაქტი“ არის შევსებული. მესიჯის ტექსტი და განმარტება იცვლება გვერდზე „ტექსტები“, ჯგუფში „შეკვეთა“.

მესიჯში ჩაწერილი ბმული ნუცასთვის მხოლოდ ონლაინ საიტიდან გაგზავნისას გაიხსნება, `localhost`-იდან გაგზავნილი ბმული მხოლოდ ამ კომპიუტერზე მუშაობს.

## ფოტოები

მიიღება JPEG, PNG და WebP, თითო ფაილი მაქსიმუმ 15 MB. HEIC ფორმატი არ მიიღება.

## ლოგო

ლოგო მთავარ გვერდზე დიდად ჩანს. ადმინპანელიდან ატვირთე კვადრატული PNG გამჭვირვალე ფონით, მინიმუმ 1000px. JPEG-ს გამჭვირვალე ფონი არ აქვს, ამიტომ კუთხეები შეიძლება შავად გამოჩნდეს. ახლანდელი ლოგოს გამჭვირვალე ვერსია არის `seed/images/logo.png`.
